# Anastasia Shabanova, translator website

Bilingual (English / Russian) multi-page site: home, about, services and prices, portfolio, reviews and contact.

Everything is in `index.html`. The site content lives in the `site-data` block near the top of the body, so texts and prices can be changed there without touching the layout.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, Deploy from `main`, folder `/ (root)`.
3. The site goes live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
